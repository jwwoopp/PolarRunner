# 15,000m 코스 확장 및 속도 곡선 조정

## 문제

- 내부 코스가 5000m라 평균 속도 약 25 기준 3~4분 만에 끝났다.
- HUD 목표인 남극~북극 20,004km를 약 10분 동안 달리는 구성과 맞지 않았다.
- 코스 길이만 늘리면 5000m 이후 지형, 장애물, 별과 Enemy가 없는 빈 구간이 생긴다.

## 해결

- 내부 `courseDistance`를 5000m에서 15,000m로 확장했다.
- 검증된 첫 5000m 도로 구성을 두 차례 이어 붙이고 중간 반복은 좌우 반전했다.
- 랜덤 장애물과 별 생성 범위를 15,000m까지 확장했다.
- 기존 해안 Enemy 구간도 5000m 간격으로 두 차례 추가했다.
- 진행 속도를 내부 거리 기준 `16 → 20 → 24 → 28 → 32 → 35`로 조정했다.
- Enemy 발사 난이도는 0~5000m, 5000~10000m, 10000m 이후로 나눴다.

## 설계 기준

- 장애물과 별은 별도 배율을 사용하지 않고 공통 `runSpeed`로 접근한다.
- 평균 속도 약 25에서 15,000m를 달리면 약 600초(10분)가 된다.
- 최고 속도 구간에서도 장애물 최소 간격을 유지해 불가능한 연속 입력을 방지한다.

## 플레이 테스트 항목

- [ ] 5000m와 10000m 경계에서 도로가 끊기거나 튀지 않는지 확인
- [ ] 5000m 이후에도 장애물과 별이 계속 등장하는지 확인
- [ ] 반복 해안 구간에서 Enemy가 바다 방향에 정상 등장하는지 확인
- [ ] 후반 SPEED 32~35에서 장애물 간격이 회피 가능한지 확인
- [ ] 약 10분 후 HUD 20,004km와 Goal이 함께 도달하는지 확인
