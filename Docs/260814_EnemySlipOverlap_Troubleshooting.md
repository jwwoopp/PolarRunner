# Enemy 전투와 Slip 지형 중첩 문제

## 문제

- Enemy 탄환을 피하는 동안 좁고 미끄러운 얼음길까지 함께 등장해 난도가 갑자기 높아졌다.
- Enemy가 제거될 때만 Slip을 다시 표시하는 방식은 지형이 순간 교체되는 문제를 다시 만들 수 있었다.

## 원인

- Enemy는 한 번 생성되면 격추될 때까지 플레이어를 계속 추격했다.
- 코스 지형은 고정되어 있으므로 전투가 길어지면 다음 `NarrowIcePath` 구간까지 자연스럽게 겹쳤다.
- 렌더링 단계에서 Slip을 임시로 숨기면 실제 코스와 화면 표현이 달라진다.

## 해결

- 실제 맵과 렌더링 데이터는 변경하지 않았다.
- 앞 220m 안에 `NarrowIcePath`가 있으면 Enemy 신규 스폰을 허용하지 않는다.
- 활성 Enemy가 Slip 120m 앞까지 남아 있으면 후퇴시키고 기존 Enemy 탄환도 제거한다.
- 의도적인 후퇴에서는 해안 강제 유지 타이머를 시작하지 않아 다음 Slip을 가리지 않는다.
- 따라서 플레이어는 충분히 먼 거리부터 Slip 지형을 그대로 확인할 수 있다.

## 확인 항목

- [ ] Enemy 전투 중 Slip 구간이 갑자기 나타나지 않는지 확인
- [ ] Slip 접근 전에 Enemy와 기존 탄환이 정리되는지 확인
- [ ] Enemy 후퇴 직후 지형이 다른 맵으로 순간 교체되지 않는지 확인
- [ ] Slip 지형이 먼 거리부터 정상적으로 보이는지 확인
- [ ] Slip 이후 안전한 해안 구간에서 Enemy가 다시 등장하는지 확인
