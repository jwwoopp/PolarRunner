# CodeStateViewer — 이름이 생기는 순간

C++ 코드와 파이썬 코드를 **한 줄씩 나란히 실행**하면서, 그 시점에 이름(변수)이
존재하는지·값이 무엇인지를 디버거의 지역 변수 창처럼 보여주는 학습용 도구입니다.

Visual Studio에서 중단점을 선언 줄 **앞**에 찍었을 때와 **뒤**에 찍었을 때 값이 달라
보이는 이유가 그대로 재현됩니다.

```
Tools/CodeStateViewer/index.html   ← 브라우저로 그냥 열면 됩니다 (서버 불필요)
```

## 무엇을 보여주나

| 왼쪽 (C++) | 오른쪽 (Python) |
|---|---|
| 컴파일러가 위에서 아래로 읽으며 **그 자리에서** 이름을 확인 | 그 줄이 **실제로 실행될 때** 이름을 찾음 |
| 이름이 없으면 `C2065` — 실행 파일 자체가 안 만들어짐 (단계 0개) | 일단 실행되다가 그 줄에서 `NameError` |
| 선언만 한 지역 변수는 쓰레기 값 (`-858993460` = 디버그 빌드 `0xCC`) | "선언만" 이라는 상태가 없음 — 대입 전에는 이름 자체가 없음 |
| `{ }` 가 스코프 — 닫는 중괄호에서 소멸 | `if` / `for` 는 스코프를 만들지 않음, 함수만 스코프 |
| 함수 몸체도 정의 시점에 이름 검사 | 함수 몸체는 호출될 때 처음 검사 |

## 사용법

- 위쪽 탭에서 시나리오를 고르고 **다음**(또는 `→` 키)을 누르면 두 쪽이 한 단계씩 진행합니다.
- 강조된 줄은 **아직 실행하지 않은, 다음에 실행할 줄**입니다. 그래서 그 줄의 대입은 상태에 아직 반영돼 있지 않습니다.
- 코드의 아무 줄이나 클릭하면 중단점처럼 그 줄에 멈추는 단계로 건너뜁니다.
- 레인 오른쪽 위 **편집**을 누르면 자기 코드를 붙여넣을 수 있고, 다시 누르면 그 코드로 실행합니다.
- `←` `→` `Home` `End` 키로도 진행합니다. 오른쪽 위 **화면 전환**으로 밝은/어두운 화면을 바꿉니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조와 스타일 (여기가 마크업/CSS 원본) |
| `engine.js` | 렉서 → 파서 → C++ 선언순서 정적검사 → 제너레이터 실행기 → 단계 스냅샷 |
| `examples.js` | 시나리오별 C++ / Python 예제 짝 |
| `app.js` | 렌더링과 조작 |

의존성 없는 정적 파일 4개뿐입니다. 빌드 과정이 없으니 파일을 고치고 새로고침하면 됩니다.
(웹 폰트 `IBM Plex`만 온라인에서 받아옵니다. 오프라인이면 기본 글꼴로 대체됩니다.)

## 지원 범위

실제 컴파일러/인터프리터가 아니라 **학습용 축소 실행기**입니다.

- **공통** — 변수, 산술·비교·논리 연산, `if / else`, `while`, `for`, 함수 정의·호출·재귀
- **C++** — `int double bool string`, 선언과 초기화, 블록 스코프 `{ }`,
  `cout << ... << endl`, `(double)x` / `static_cast`, `++ -- += -=`.
  `#include` 와 `using namespace std;` 는 읽고 넘어갑니다.
  `main()` 이 있으면 전역 초기화 뒤 `main()` 부터 실행하고, 없으면 위에서부터 실행합니다.
- **Python** — 대입, `def`, `print`, `range len int float str bool abs`,
  리스트 리터럴과 인덱싱, `global`, `//`, `UnboundLocalError` 재현
- **아직 안 되는 것** — 클래스, 포인터·참조, 배열, 템플릿, 예외, import,
  딕셔너리, 슬라이싱, f-string

범위를 벗어난 코드는 "문법 오류"로 표시되며 어느 줄에서 막혔는지 알려줍니다.

## 정확도에 대해

C++ 쪽 오류 번호(`C2065`, `C3861`, `C2374`, `C4700`)와 초기화 안 된 int 의
`-858993460` 은 MSVC 디버그 빌드의 실제 동작을 따라 맞춘 값입니다.
다만 초기화 안 된 값이 실제로 무엇인지는 표준이 보장하지 않습니다 —
"실행할 때마다 달라질 수 있다"는 점을 보여주려고 디버그 빌드의 채움 값을 쓴 것입니다.
