# PolarRunner 별 수집 및 HUD 개선

## 문제

- 점프 중 별과 화면상 Y 좌표가 겹치면 별이 수집되었다.
- 전체 화면을 `#` 테두리로 감싼 HUD가 게임 화면을 과도하게 차지했다.
- 현재 거리 숫자는 있었지만 별과 SHOT 보유 상태를 빠르게 읽기 어려웠다.

## 원인

- 별 수집 판정이 점프한 플레이어의 화면상 몸통 범위까지 허용했다.
- HUD 테두리를 콘솔 전체 너비로 출력해 게임보다 UI가 강하게 보였다.
- 별과 SHOT을 숫자로만 출력해 즉시 확인하기 어려웠다.

## 해결

- 점프 중에는 별 수집 검사를 하지 않도록 변경했다.
- 전체 화면 테두리와 진행률 막대를 제거했다.
- 좌측 상단에만 폭 62칸의 작은 HUD 패널을 배치했다.
- 별은 `*`, SHOT은 탄환과 같은 `@`를 사용해 각각 5칸으로 표시했다.
- 환산된 현재 거리와 최종 목표 거리 `20004km`를 함께 표시했다.

```text
+------------------------------------------------------------+
| POLAR RUNNER  DIST: 216 m / 20004 km                       |
| SPEED: 16.8  ROAD: STRAIGHT                                |
| STAR: [****-] 4/5                                          |
| SHOT: [@@---] 2                                            |
+------------------------------------------------------------+
```

## 결과

- 별은 지상에서 같은 레인과 진행선에 있을 때만 수집된다.
- HUD가 좌측 상단에만 표시되어 게임 화면을 덜 가린다.
- 거리, 별, 탄환 상태를 한눈에 확인할 수 있다.

## 검증

- Debug x64 컴파일 성공
- 경고 0개, 오류 0개
- 실제 화면에서 패널 크기와 알림 위치를 추가 확인할 필요가 있다.
