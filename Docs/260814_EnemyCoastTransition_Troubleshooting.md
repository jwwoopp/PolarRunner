# Enemy 제거 직후 해안 지형 전환 문제

## 문제

- Enemy를 명중시켜 제거하면 약 1초 동안 원래 코스 지형이 순간적으로 보였다.
- 바다와 해안이 자연스럽게 유지되지 않고 화면이 다른 맵으로 교체되는 것처럼 느껴졌다.

## 원인

- Enemy는 Actor 충돌 처리 중 제거되지만 `coastVisualHoldTimer`는 다음 `PolarLevel::Tick()`에서 시작됐다.
- 제거 프레임에는 Enemy가 만료된 상태이고 타이머는 아직 0이라 원래 지형이 한 프레임 노출됐다.
- 기존 전환은 유지 시간 동안 행별로 원래 지형을 다시 보여주는 방식이라 깜빡임이 더 오래 보였다.

## 해결

- `coastEnemyWasActive`를 이용해 Enemy가 제거된 바로 그 프레임도 해안으로 출력했다.
- Enemy가 보이거나, 해안 유지 타이머가 남았거나, 직전 프레임에 Enemy가 활성 상태였다면 화면 전체의 해안 표현을 유지하도록 변경했다.
- 유지 시간 중 원래 지형을 행별로 노출하던 전환 계산을 제거했다.
- 바다 방향도 같은 조건으로 고정해 좌우 해안이 뒤집히지 않도록 했다.

## 확인 항목

- [ ] Enemy 명중 직후 다른 지형이 한 프레임이라도 보이지 않는지 확인
- [ ] Enemy 제거 후 정해진 시간 동안 해안 전체가 유지되는지 확인
- [ ] 유지 중 바다의 좌우 방향이 바뀌지 않는지 확인
- [ ] 다음 실제 코스 지형으로 넘어갈 때 화면 깜빡임이 없는지 확인
