# Enemy 전투 중 지형이 갑자기 바뀌는 문제

## 문제

Enemy가 등장하거나 제거될 때 해안이 다른 지형으로 순간 전환되거나, 이후 코스가 갑자기 사라져 보였다.

## 원인

렌더링 코드가 Enemy의 생존 상태를 확인한 뒤 모든 `RoadSlice`의 지형을 `Coast`로 강제 변경하고 있었다. 따라서 실제 코스 데이터와 화면에 표시되는 지형이 서로 달라졌다.

## 해결

- 화면 지형은 항상 `CalculateRoadSlice()`가 반환한 코스 데이터만 사용한다.
- Enemy의 등장 여부는 해안 구간 안에서만 판단한다.
- 해안 구간이 끝나면 남아 있는 Enemy와 Enemy 탄환을 정리한다.
- 바다의 좌우 방향은 Enemy 상태가 아니라 해당 해안 구간 데이터로 결정한다.

## 결과

Enemy가 등장하거나 제거되어도 맵은 원래 코스 순서대로 유지되며, 전투 상태가 지형 렌더링을 바꾸지 않는다.
